Occupancy Prediction

How it works

The model is k-nearest neighbors regression. It compares your inputs (room type, capacity, day, hour, class scheduled, class size as a share of capacity) with past simulated records, finds the k most similar ones, and averages their occupancy rate. Number features are scaled to 0–1 so none dominates; a different room type adds a distance penalty. The result is kept between 0 and the room capacity. It learned only from simulated data, not real campus data.

Demonstration evaluation results

MAE = average size of the error in occupants. RMSE is similar but punishes big misses more. The baseline always guesses the average training occupancy; the model is useful only if its errors are lower. Scores on simulated data do not prove real-world accuracy.

Room Scheduling

Mandatory rules: capacity, room type, equipment, no overlap on the same day (back-to-back is allowed). Preferences: less unused capacity scores higher; the preferred room gets +5. Suggestions are not official schedules.
